🌐 Koneksi API Backend GAS (Vercel / GitHub)

Mode Lokal / Demo

Saat di-hosting di Vercel, Netlify, atau GitHub Pages, tempelkan URL Deployment Google Apps Script (https://script.google.com/macros/s/.../exec) di bawah ini atau isi konstanta GAS_WEB_APP_URL di dalam kode index.html.

📊 Skema 5 Sheet Google Sheets (Master Blueprint)

Fungsi setupDatabase() pada Code.gs otomatis membuat kelima sheet ini beserta header kolomnya:

Nama Sheet Struktur Kolom
1. Settings Parameter | Nilai
2. Links ID | Judul Tautan | URL | Ikon | Status
3. Produk_KDMP ID | Nama Produk | Harga | Deskripsi | ID_Foto_Drive | No_WA_Pemesanan | Status
4. Potensi_UMKM ID | Nama | Pengelola/Desa | Deskripsi Singkat | ID_Foto_Drive | No_WA_Kontak | Status
5. Admin Username | Password (SHA-256) | Token_Sesi
